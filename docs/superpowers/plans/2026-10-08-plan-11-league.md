# Plan 11: A League of Past Nets and Scripted Styles in Self-Play (Sub-project 3d-3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mix other opponents into self-play: with `fast-loop --league NET [NET ...]`, each self-play game is, with probability 1/2, a league game in which two seats are the learner and two are pool bots (one past net, one scripted style: `style:roads`, `style:army`, `style:production`), recorded only at the learner seats; then measure it: arm E, a 3-hour `fast-loop` with the best arm so far's settings plus `--league`, settled by an SPRT of `net:E@100+t[+o]` against three copies of the control's best, and a robustness line against each style.

**Architecture:** `settler_bots::heuristic` gains the three style weight sets (`STYLES`, `STYLE_FACTOR`, `style_weights`), and `make_bot` a `style:STYLE` name form, so every entry point that takes a bot name (the arena, `sprt`, `Roster`, `Bot`) takes a style. `settler_bots::selfplay` gains `League` (pool bot names checked and their files loaded once by a `Roster`, and the seeded draw of a game's league seats) and `play_with_league` / `run_with_league` (`Option<&League>`); `play_with_opening` / `run_with_opening` call them with `None`, so every existing caller and pinned digest is unchanged. Learner seats stay `IsmctsBot<E>`; league seats are `Box<dyn Bot>` built from names, moved with `Bot::act`, and never recorded. The binding `selfplay_explore` gains `league_nets=` / `league_styles=`. Python threads it through `selfplay.write_explore(league=)` (the record's `selfplay` block names the pool; a league game's record names its seats) and `FastLoop` (`state.json`), which copies the set-up nets to `<dir>/nets/league-NNN.bin`, adds every net it promotes, and keeps the pool on every resume. The controller then prepares the pool at the build's encoder, runs arm E with `runs/p2/arm.sh` unchanged, the SPRT and the robustness arenas, and writes `docs/bot/results-3d3.md`.

**Tech Stack:** Rust 1.80+ (edition 2021, no new crates), PyO3 0.29.3 + maturin 1.15.0, Python 3.12 stdlib, PyTorch 2.14.1 (`train` extra only), pytest 9.1.1.

**Spec:** `docs/superpowers/specs/2026-10-08-league-design.md` (binding). Builds on Plan 9 (`docs/superpowers/plans/2026-10-08-plan-9-opening-selfplay.md`: `play_with_opening` / `run_with_opening`, how `fast-loop --opening` is kept from set-up, `selfplay.opening_mismatch`, arm C, `docs/bot/results-3d1b.md`) and Plan 10 (`docs/superpowers/plans/2026-10-08-plan-10-encoder-v4.md`: encoder v4, `alphasettler net-upgrade` for v3 nets, `runs/3d2/gen-034-v4.bin`, arm D, `runs/3d2/nets/`, `docs/bot/results-3d2.md`). ## Where the code forces a choice the spec does not make

Each is a **Ruling** (with its reason) the results file repeats, so it can be overridden.

- **A style's name is `style:STYLE[@N[+rD]]`, with the `ismcts` suffixes `+sK`, `+t` and `+g` in any order, never `+o`.** It follows `net:NAME`: a prefix naming what the bot is, then the `ismcts` budget grammar. STYLE is `roads`, `army` or `production`; `style:roads` alone is 1,000 simulations, as `ismcts` is. The bot is `IsmctsBot::new`'s bot with the style's weights and reports the name `style`. `make_bot` builds it, so `Roster`, the arena, `sprt`, `Bot(...)` and the league take it with no file to load.
- **The styles live in `settler_bots::heuristic` as a table of feature names** (`STYLES`), each style's weights `DEFAULT_WEIGHTS` with its named features times `STYLE_FACTOR` (3.0): roads 0.05 → 0.15 (`road_length`) and 0.2 → 0.6 (`settlement_spots`); army 0.3 → 0.9 (`dev_cards`) and 0.1 → 0.3 (`knights`); production 0.08 → 0.24.
- **The league is a parameter of new entry points, not a field of `Exploration`.** `Exploration` is `Copy` and built by struct update throughout the tests; a pool holds loaded nets. `play_with_league(..., opening, league: Option<&League>)` and `run_with_league(..., threads, opening, league)` hold the game loop; `play_with_opening` and `run_with_opening` keep their signatures and call them with `None`, so every caller and every pinned digest is unchanged.
- **Heterogeneous seats with the least change: the four learner `IsmctsBot<E>`s are built exactly as now** (same names, seeds, configs and evaluators), **and a league seat's bot is a `Box<dyn Bot>` from the pool's `Roster`**, seeded `bot_seed(seed, seat)` like the learner it replaces. The learner bot of a league seat is never shown an event or asked to move. A league seat is moved with `Bot::act` (its own name's budget, its own `+o`), after its events are delivered; it draws nothing from the exploration stream and records nothing.
- **The draw has its own stream** (`LEAGUE_SALT`): one `unit` (a league game if below 0.5), the first league seat `below(4)`, the second `below(3)` skipping the first, then the net's index, then the style's. So a plain game in a league run is exactly the game a run without a league plays from that seed, and the seats do not depend on the learner, the opening model or the exploration settings.
- **"Half the league seats are past nets, half styles" is exact per game:** every league game has one past-net seat and one style seat, so styles are exactly a quarter of a league game's seats, as the spec's ruling wants, with no game of two styles or two nets.
- **Records:** a league game's record gains `league`, a list of four entries (the pool bot's name at a league seat, null at a learner seat); a plain game's record has no such key. With a league, the `selfplay` block gains `league_probability`, `league_nets` and `league_styles`; without one, records are byte-identical to before. Value targets: the trainer reads value rows at recorded decisions, so a league game's result is a value target at the learner seats' positions (as every game's result is at its decisions).
- **`--league` takes the set-up pool's net files** (`--league NET [NET ...]`, first run only): the spec names the flag and says the set-up nets differ by arm, so they are its arguments. They are checked by the Rust loader before anything is written, copied to `nets/league-000.bin`, `league-001.bin`, ... in the order given (names that cannot collide with `start`, `best` or `gen-NNN`), and kept by sha256 under `"league"` in `state.json` (`{"nets": [{"name", "source", "sha256"}, ...]}`, null without a league).
- **The pool grows at the generation boundary:** generation k's pool is the set-up nets plus every generation before k whose gate promoted it (state.json is the record), so a promoted net is met from the next generation on, the current best included.
- **League seats' budget is `FastLoopSettings.league_simulations`**, default `SELFPLAY_FAST_SIMULATIONS` (100) and not on the CLI, which the spec fixes; tests set it lower to stay fast.
- **Loops keep the pool:** a resume without `--league` keeps it; `--league` with the same files (the same sha256 list, in order) is accepted; other files, or `--league` on a loop set up without one, are refused (exit 2). This reads the spec's "refuses `--league` on resume of a loop set up without it (and the reverse)" as Plan 9 read `--opening`: the reverse is a league loop refusing another pool; it is never resumed without its pool, because a resume without the flag keeps it. A `state.json` from before 3d-3 has no `league` key and reads as without.
- **The copies are checked before use:** before every generation's self-play, each `nets/league-NNN.bin` is checked against its sha256; a missing or changed copy stops the loop with an error naming the file. Promoted generations' files are the loop's own nets and are not re-hashed.
- **Each generation's `selfplay` entry gains `"league"`:** null without a league, else `{"nets", "styles", "games", "seats"}` (the pool's names, the number of league games, and the seats each pool bot took), which is what the results' share table reads.
- **The gate is unchanged** (`net:gen-NNN@SIMS+t[+o]` against the best): the league changes self-play only. **Only `fast-loop` gets the flag:** the spec names no other loop and no `alphasettler selfplay` flag.
- **The robustness line plays each style in turn:** "three bots drawn from the style half of the pool" is run as three arenas per net, each against three copies of one style (`style:STYLE@100+t`) on the same 200 seeds from 6,001,000,000, each reported with z vs 0.25, plus a pooled line over the three. An exhaustive draw has no draw variance and shows which style, if any, exploits a net; the arena is unchanged. Cost if wrong: three runs per net instead of one mixed table.
- **Arm E runs on this build's encoder, v4 in every branch** (Plan 10: "the build is v4 either way"), from `runs/3d2/gen-034-v4.bin` (gen-034 upgraded, outputs within 1e-5 of gen-034), through `runs/p2/arm.sh` unchanged. If the control is arm D, E's settings are exactly D's (D's set-up line). If the control is arm C or A (3d-2 not H1), E's settings are the control's plus the upgraded start, and the SPRT opponent is the control's best upgraded (`runs/3d2/nets/CTRL.bin`, Plan 10 Step 6); E then also differs by the v4 inputs, which 3d-2 measured as no gain, and the results file says so.
- **Pool nets are prepared at set-up for the build's encoder:** each source (`runs/3c/nets/gen-030` .. `gen-034`, then the control's promoted generations at its cut) is copied into `runs/3d3/pool/` if its header's encoding hash is `NET_ENCODING_HASH`, else upgraded there by `alphasettler net-upgrade` (v3 → v4); every result is loaded by the Rust loader before the loop is set up. With arm D as the control, gen-030 .. gen-034 are upgraded and D's own nets copied; with C or A, all are upgraded.
- **The control's best is in E's pool** (it is one of the control's promoted generations), so the SPRT opponent is a net E met in training; the spec chose this pool, and the robustness lines are the check that does not share it. The results file says so.
- **Fresh seeds:** the SPRT starts at 6,000,000,000 (at most 400 seeds, so it ends below 6,000,000,400); robustness uses 6,001,000,000 .. 6,001,000,199. No self-play (below 1e9), gate (1e9 + 0..200) or SPRT so far (2e9.., 3e9.., 4e9.., 5e9..) used them.
- **H1 makes `--league` the setting new loops are set up with**; no CLI default changes in this plan, since a resumed loop keeps its setting anyway. H0 or undecided: recorded, and the loop without it stays the default. If E's best and the control's best are the same file, the SPRT is not run and is recorded as H0 (as Plan 10 rules).
- **Task boundaries:** the league in self-play, styles included (1), the loop (2), the run (3). A reviewer can accept the seats and the draw and still reject how a loop keeps and grows its pool.

```rust
/// The prefix of a league style's name (spec 3d-3 Section 3): `style:STYLE` with an `ismcts`
/// name's budget and suffixes, STYLE one of `heuristic::STYLES`.
pub const STYLE_PREFIX: &str = "style:";

/// A fresh bot by name, with its own random stream seeded from `seed`. Besides `BOT_NAMES`,
/// `ismcts@N` (N simulations) and `ismcts@N+rD` (plus D greedy rollout moves per leaf), either
/// with `+sK` to search setup settlements with K times the simulations, `+t` to make domestic
/// offers and `+g` to search the root by Gumbel sequential halving, the suffixes in any order.
/// `style:STYLE` takes everything an `ismcts` name takes after `ismcts` (3d-3: the same bot with
/// the style's heuristic weights). `net:` names (and `+o`, which only they take) need files
/// loaded first: use a `Roster`.
pub fn make_bot(name: &str, seed: u64) -> Option<Box<dyn Bot>> {
    match name {
        "random" => Some(Box::new(random::RandomBot::new(seed))),
        "greedy" => Some(Box::new(greedy::GreedyBot::new(seed))),
        _ => {
            let (name, gumbel) = ismcts::split_gumbel(name)?;
            let (name, offers) = ismcts::split_trades(&name)?;
            let (base, factor) = ismcts::split_setup(&name)?;
            let bot = match base.strip_prefix(STYLE_PREFIX) {
                Some(rest) => style_bot(rest, seed)?,
                None => {
                    let (sims, rollout) = ismcts::parse_name(base)?;
                    ismcts::IsmctsBot::new(seed, sims, rollout)
                }
            };
            Some(Box::new(
                bot.with_setup_factor(factor)
                    .with_offers(offers)
                    .with_gumbel(gumbel),
            ))
        }
    }
}

/// `STYLE[@N[+rD]]` (a `style:` name without its prefix and flag suffixes): the bot

        settler_search::SearchConfig {
            simulations,
            ..settler_search::SearchConfig::default()
        },
        heuristic::HeuristicEvaluator::new(weights, rollout),
    ))
}
```

```rust
/// A league's pool (spec 3d-3 Section 3): bot names of past nets and of scripted styles, checked
/// and their files loaded once by a `Roster`, shared read-only by every game.
pub struct League {
    nets: Vec<String>,
    styles: Vec<String>,
    roster: Roster,
}

impl League {
    /// Both halves need a name, and every name must be a bot whose files load from `nets_dir`
    /// (the `Roster` error names the first that is not).
    pub fn new(nets: &[&str], styles: &[&str], nets_dir: &Path) -> Result<League, String> {
        fn owned(names: &[&str]) -> Vec<String> {
            names.iter().map(|n| n.to_string()).collect()
        }
        if nets.is_empty() {
            return Err("a league needs at least one past net".into());
        }
        if styles.is_empty() {
            return Err("a league needs at least one style".into());
        }
        let names: Vec<&str> = nets.iter().chain(styles).copied().collect();
        let roster = Roster::new(&names, nets_dir)?;
        Ok(League {
            nets: owned(nets),
            styles: owned(styles),
            roster,
        })
    }

    pub fn nets(&self) -> &[String] {
        &self.nets
    }

    pub fn styles(&self) -> &[String] {
        &self.styles
    }

    /// Game `seed`'s league seats: `None` for a plain game (probability
    /// `1 - LEAGUE_PROBABILITY`), else per seat the pool bot's name (`None` at a learner seat):
    /// two seats drawn uniformly from the four, the first a past net and the second a style,
    /// each uniform over its half. Every draw comes from the game's league stream, so the seats
    /// depend on the seed and the pool alone.
    pub fn draw(&self, seed: u64) -> Option<[Option<&str>; NUM_PLAYERS]> {
        let mut rng = Rng::new(mix(seed, LEAGUE_SALT));
        if unit(&mut rng) >= LEAGUE_PROBABILITY {
            return None;
        }
        let first = rng.below(NUM_PLAYERS as u32) as usize;
        let mut second = rng.below(NUM_PLAYERS as u32 - 1) as usize;
        if second >= first {
            second += 1;
        }
        let mut seats = [None; NUM_PLAYERS];
        seats[first] = Some(self.nets[rng.below(self.nets.len() as u32) as usize].as_str());
        seats[second] = Some(self.styles[rng.below(self.styles.len() as u32) as usize].as_str());
        Some(seats)
    }

    fn make(&self, name: &str, seed: u64) -> Box<dyn Bot> {
        self.roster
            .make(name, seed)
            .expect("every pool name was checked by League::new")
    }
}
```

```rust
/// league seats play their pool bots, whose moves are not recorded (spec 3d-3 Section 2). Without
/// a league, and in a plain game, this is `play_with_opening` exactly.

    config: GameConfig,
    ex: &Exploration,
    batch: usize,
    make_eval: &F,
    opening: Option<&OpeningModel>,

            name.map(|n| {
                league

                    .make(n, bot_seed(seed, p))
            })
        })
        .collect();
    let mut rng = Rng::new(mix(seed, EXPLORE_SALT));
    let mut s = State::new(seed, config);
    let (mut feed, mut buf, mut step) = (EventFeed::default(), Vec::new(), Vec::new());
    let (mut actions, mut decisions) = (Vec::new(), Vec::new());

        let a = if let Some(bot) = pool[actor].as_mut() {

                            target: r.improved,
                        });
                    }

                }
            }

            buf.contains(&a),
            "self-play chose illegal action {a:?} in phase {:?}",
            s.phase

        s.apply_with(a, None, &mut step);
        feed.push(&step);
```

```rust
pub fn run_with_league<E, F>(

    ex: &Exploration,

    make_eval: &F,
    threads: usize,
    opening: Option<&OpeningModel>,

        return Err(
            "the opening model is not used with Gumbel self-play: Gumbel self-play \
                    stays the P2 measurement it was (spec 3d-1b Section 3)"
                .into(),
        );
    }
    if ex.gumbel && league.is_some() {
        return Err(
            "a league is not used with Gumbel self-play: Gumbel self-play stays the P2 \
                    measurement it was (spec 3d-3 Section 4)"
                .into(),
        );
    }
    if batch == 0 {
        return Err("the leaf batch must be positive".into());
    }
    let n = seeds.end.saturating_sub(seeds.start);
    if n > MAX_SEEDS {
        return Err(format!("at most {MAX_SEEDS} games per call, got {n}"));
    }
    let mut games: Vec<SelfPlayGame> = std::thread::scope(|scope| {
        let workers: Vec<_> = split_seeds(seeds, threads)
            .into_iter()
            .map(|part| {
                scope.spawn(move || {
                    part.map(|seed| {
                        play_with_league(seed, config, ex, batch, make_eval, opening, league)
                    })
                    .collect::<Vec<_>>()
                })
            })
            .collect();
        workers
            .into_iter()
            .flat_map(|w| {
                w.join()
                    .unwrap_or_else(|panic| std::panic::resume_unwind(panic))
            })
            .collect()
    });
    games.sort_by_key(|g| g.seed);
    Ok(games)
}
```

```python
def check_league_nets(paths: list[str | Path], gumbel: int | None = None) -> list[str]:
    """The sha256 of each of a league's set-up net files, once the Rust loader every `net:` bot uses has
    read it (a ValueError starting `league net PATH:` otherwise: missing, cut short, another encoder).
```

```python
def league_mismatch(root: str | Path, stored: dict | None, asked: list[str | Path] | None) -> str | None:
    """The error for asking `--league NET ...` of a loop in `root` set up with the league `stored` (its
    state.json entry; None: without one, as every loop from before 3d-3 was), or None if the ask is
    allowed: no flag keeps the loop's pool, the same files (by sha256, in order) repeat it."""
    if asked is None:
        return None
    if stored is not None and [files.sha256_file(p) for p in asked] == [n["sha256"] for n in stored["nets"]]:
        return None
    if stored is None:
        was = "without --league"
    else:
        was = f"with another league pool ({', '.join(n['source'] for n in stored['nets'])})"
    return f"{root} was set up {was}, and a loop keeps the league it was set up with"
```

```python
    def init(root: str | Path, seed_dirs: list[str | Path], start_net: str | Path, first: int,
             trades: bool = False, gumbel: int | None = None, opening: str | Path | None = None,
             league: list[str | Path] | None = None) -> None:
        """Create `root` with `seed_dirs` (oldest first) as the starting records and `start_net`
        as the best net; generation numbering starts at `first`; `trades` plays the trading game;
        `gumbel` (simulations) makes every self-play move a Gumbel root search; `opening` (an
        opening model file, copied to `nets/opening.bin`) picks self-play's setup settlements;
        `league` (net files, copied to `nets/league-NNN.bin` in order) makes about half the self-play
        games league games against them, the nets this loop promotes and the three styles."""
        root = Path(root)
        if (root / STATE).exists():
            raise ValueError(f"{root / STATE} exists: the loop is already set up (resume it with fast-loop)")
        if gumbel is not None:
            selfplay_mod.check_gumbel(gumbel)
        opening_sha256 = None if opening is None else selfplay_mod.check_opening(opening, gumbel)
        league_sha256 = None if league is None else selfplay_mod.check_league_nets(league, gumbel)
        nets = root / "nets"

        files.atomic_copy(start_net, nets / "start.bin")
        files.atomic_copy(start_net, nets / "best.bin")
        if opening is not None:
            files.atomic_copy(opening, nets / OPENING_FILE)
        pool = None
        if league is not None:
            pool = {"nets": []}
            for i, (src, digest) in enumerate(zip(league, league_sha256)):
                name = f"{LEAGUE_NET_PREFIX}{i:03d}"
                files.atomic_copy(src, nets / f"{name}.bin")
                pool["nets"].append({"name": name, "source": str(Path(src).resolve()), "sha256": digest})
        dirs = [str(Path(d).resolve()) for d in seed_dirs]
        state = {"seed_dirs": [{"dir": d, "games": count_games(Path(d))} for d in dirs],
                 "first": first, "trades": trades, "gumbel": gumbel, "opening": opening_sha256, "league": pool,
```

```python
    def league_pool(self) -> dict | None:
        """The pool this generation's league games draw from (spec 3d-3 Section 3), as bot names: the
        set-up nets (each copy checked against the sha256 it was set up with; ValueError if missing or
        changed), then every generation this loop has promoted, oldest first, each
        `net:NAME@SIMS[+t][+o]`; and the three styles, `style:STYLE@SIMS[+t]`. None without a league."""
        if self.league is None:
            return None
        for n in self.league["nets"]:
            path = self.nets / f"{n['name']}.bin"
            if not path.is_file() or files.sha256_file(path) != n["sha256"]:
                raise ValueError(f"{path} is not the league net {self.root} was set up with (sha256 {n['sha256']}, "
```

- [ ] **Step 2: The pool at this build's encoder (controller runs this)**

The set-up pool (spec Section 3): the trading loop's gen-030 .. gen-034, then the control's promoted generations at its cut, oldest first. Each is copied into `runs/3d3/pool/` if it is already at this build's encoder, else upgraded there by `net-upgrade` (v3 → v4: gen-030 .. gen-034 always; arm C's or A's generations too; arm D's are copied), and loaded by the Rust loader:

```bash

mkdir -p runs/3d3/pool
.venv/bin/python3 - <<'EOF' | tee runs/3d3/pool.log
import json, os, shutil, struct, subprocess
from pathlib import Path
from alphasettler._engine import NET_ENCODING_HASH, resolve_net
ctrl = os.environ["CTRL"]
state = json.load(open(f"runs/p2/{ctrl}-state-at-cut.json"))
sources = [Path(f"runs/3c/nets/gen-{k:03d}.bin") for k in range(30, 35)]
sources += [Path(f"runs/p2/{ctrl}/nets/gen-{g['gen']:03d}.bin") for g in state["generations"] if g["gate"]["promoted"]]
out = []
for src in sources:
    dst = Path("runs/3d3/pool") / f"{src.parent.parent.name}-{src.stem}.bin"  # 3c-gen-030, D-gen-035, ...
    if struct.unpack_from("<Q", src.read_bytes(), 12)[0] == NET_ENCODING_HASH:
        shutil.copyfile(src, dst)
        how = "copied (already this build's encoder)"
    else:
        r = subprocess.run([".venv/bin/alphasettler", "net-upgrade", str(src), str(dst)], capture_output=True,
                           text=True, check=True)
        how = r.stdout.strip()
    resolve_net(dst.stem, str(dst.parent))
    print(f"{dst} from {src}: {how}")
    out.append(str(dst))
Path("runs/3d3/pool.txt").write_text("\n".join(out) + "\n")
print(f"{len(out)} pool nets: 5 from runs/3c, {len(out) - 5} promoted by {ctrl}")
EOF
```

```markdown
## Rulings the build made

- Styles are `style:STYLE[@N[+rD]]` bots (the `ismcts` suffixes but `+o`): the heuristic ISMCTS bot
  with the style's weights, a table of feature names times 3.
- The league is a parameter of new self-play entry points (`play_with_league`, `run_with_league`);
  without a league self-play is unchanged (the 3a, P2 and 3d-1b digests pass through them).
- The learner's four bots are built as before; a league seat plays a pool bot built from its name
  (seeded as the learner it replaces) with its own search, records nothing and draws nothing from
  the exploration stream.
- The draw has its own stream, so a plain game in a league run is the game a plain run plays; every
  league game has exactly one past net and one style.
- A league game's record names its seats under `league`; records without a league are
  byte-identical to before. `--league` with `--gumbel` is refused, in Rust and in Python.
- `--league` takes the set-up nets, copied to `nets/league-NNN.bin` and kept by sha256; the pool
  grows by each promoted generation from the next generation on; a resume without the flag keeps
  the pool, other files are refused, a changed copy stops the loop. The gate is unchanged.
- Robustness plays each style in turn (three arenas per net on the same seeds) and a pooled line.
- Arm E ran through `runs/p2/arm.sh` unchanged at encoder v4 from gen-034 upgraded; pool nets were
```
